# Growth scorecards

**Operational period:** Oct 16, 2026 – Jan 13, 2027 ([90-day checklist](../nypllc-90-day-execution-checklist.md)).

## Cadence

| Artifact | When | Owner |
|----------|------|-------|
| **Weekly** (`YYYY-Www.md` or dated file) | Before Sid’s ~30m commercial review | Agent prepares; Sid decides |
| **Monthly** (`YYYY-MM.md`) | First business day of month (after weekly format is stable) | Agent |

**Rule:** Manual weekly table first (P1-06). Automate only after the format stops changing — see `PLLC-CRM/crm/scripts/weekly-scorecard-export.ts`.

## Evidence

Each work package should leave a short completion note (checklist § Evidence to retain): task ID, what changed, link to export/screenshot, counts, decision.

## Metric definitions

Use stable definitions from [nypllc-90-day-execution-checklist.md § Minimum scorecard definitions](../nypllc-90-day-execution-checklist.md). Integrated plan §10 mirrors these after v3.
